## ⚡ Why Use Label Crop AI?

Online marketplace seller panels (Meesho Supplier Panel, Flipkart Seller Hub, Amazon India) bundle shipping labels and tax invoices together on standard A4 PDF pages. 

Printing these raw pages directly on 4-inch direct thermal printers causes major dispatch issues:
1. **Shrunken, Unscannable Barcodes**: The printer driver scales the entire A4 page down onto one 4×6 sticker, producing tiny barcodes that logistics scanners (Valmo, Ekart, Delhivery, Shadowfax) cannot read.
2. **Expensive Paper Waste**: Up to 50% of costly thermal sticker rolls are wasted printing full tax invoices that should be filed digitally or printed on ordinary paper.
3. **Manual Handover Chaos**: Hundreds of mixed parcels have to be sorted manually by courier partner when pickup riders arrive.

**Label Crop AI** solves this instantly by processing multi-page PDFs directly inside the client's web browser or mobile app.

## 🚀 Key Features

* **⚡ Smart 1-Click Auto-Crop**:
  * **[Meesho Label Crop](https://labelcropai.web.app/meesho-label-crop)**: Cuts cleanly above the *Fold Here* line or invoice box border, isolates the shipping label, and **auto-rotates 90°** to fill 4×6 thermal rolls.
  * **[Flipkart Label Crop](https://labelcropai.web.app/flipkart-label-crop)**: Cuts at the dashed boundary line above the Tax Invoice and trims margins for Ekart-ready stickers.
  * **[Amazon Label Cropper](https://labelcropai.web.app/amazon-label-crop)**: Separates Amazon Easy Ship and Flex labels from customer invoice sheets.
  * **Shopsy & Snapdeal**: Full multi-layout compatibility.
* **✂️ Separate Tax Invoices**:
  * **Labels Only**: Print just the shipping label stickers (save 50% on thermal paper rolls).
  * **Label + Invoice**: Print each invoice right after its matching label.
  * **[Invoices on A4](https://labelcropai.web.app/remove-invoice-from-labels)**: Export all tax invoices into a single A4 PDF for accounting or normal printing.
* **🚚 Courier-Wise Batch Sorting**:
  * Sorts packages automatically by courier: **Valmo, Ekart Logistics, Delhivery, Shadowfax, Xpressbees, Ecom Express, Blue Dart, and India Post**.
  * Handover summary totals COD and prepaid parcels per courier for rider sign-off.
* **📋 [SKU Picklist Generator](https://labelcropai.web.app/sku-picklist-generator)**:
  * Generates a printable warehouse picklist PDF summarizing units needed by SKU, size, and color.
  * Exports full dispatch details to an Excel/Sheets-friendly **Orders CSV**.
  * Multi-quantity orders are highlighted with a bold black **`QTY`** tag on the label.
* **📄 [A4 Sticker Sheet Converter](https://labelcropai.web.app/a4-sticker-sheet-label-cropper)**:
  * No thermal printer yet? Print on laser or inkjet printers with **2-up, 4-up, 6-up, or 8-up** layouts with dashed cut guides.
* **🔒 100% Client-Side Privacy**:
  * PDF files **never leave your device**. Built with open-source client-side engines (Mozilla PDF.js and pdf-lib).
  * Customer names, phone numbers, and delivery addresses are never sent to external servers. Works completely offline after first use!

## 🛠️ Local Development & Project Structure

This project is built as a lightning-fast static progressive web app (PWA) with zero runtime dependencies.

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Commands

```bash
# Clone the repository
git clone https://github.com/iammannan/label-crop-ai.git
cd label-crop-ai

# Install developer dependencies
npm install

# Build static output and sitemaps (public/)
npm run build

# Start local development server (port 5000)
npm run dev

# Run SEO & schema audit checks
npm run seo-audit

# Run end-to-end headless browser test suite
npm test
```

### Deployment

Deploy to Firebase Hosting:
```bash
npm run deploy
```
